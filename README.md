# R&R's Threadful  
##### A Nostalgic Platformer Made By College Students for Game Publishing at Georgian College  
> You are Hopps, a beloved bunny doll that was accidentally left behind at a daycare.  
> Make your way through the toys to the lost and found box to get back to your owner.

# Run Instructions
Threadful is mainly a Windows only EXE file made in Unity. On [our Itch.io](https://talonolat.itch.io/threadful) there will be a web build and a download to an exe build of the game. The exe build is preferred, but the web build should be playable. Download the zip, and run the Threadful.exe file to open the game. Have fun!  
(You can also clone the project yourself and open it in Unity)
